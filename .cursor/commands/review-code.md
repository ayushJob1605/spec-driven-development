# Review Code

Review the selected implementation against the approved specification.

## Compare

Check:

Requirement

→ Specification

→ Implementation

→ Tests

## Review

Look for:

- specification deviations

- incorrect business logic

- incorrect API behavior

- validation problems

- security issues

- transaction problems

- concurrency issues

- database problems

- error handling problems

- performance issues

- unnecessary complexity

- unnecessary dependencies

- dead code

- test gaps

## AI Mistakes

Identify meaningful mistakes or incorrect suggestions made by AI.

Do not invent findings.

## Output

For every finding provide:

- Severity

- Location

- Problem

- Evidence

- Specification reference

- Impact

- Recommended fix

Then provide:

### AI Mistakes Identified

### Specification Deviations

### Test Gaps

### Recommended Fixes

Do not modify code during this review.
