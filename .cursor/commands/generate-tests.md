# Generate Tests

Generate tests based on the approved specification.

Do not begin by simply inspecting implementation and generating

tests that reproduce the implementation.

## Process

1. Read the relevant requirements.

2. Read acceptance criteria.

3. Read business rules.

4. Read API contracts.

5. Read state transitions.

6. Identify expected behaviors.

7. Identify negative cases.

8. Identify boundary conditions.

9. Map requirements to test scenarios.

10. Inspect the implementation.

11. Generate appropriate tests.

12. Review generated tests for false positives.

## Test Quality

Ensure tests contain meaningful assertions.

Check for:

- missing edge cases

- incorrect expected values

- excessive mocking

- implementation-detail testing

- false positives

- unrealistic test data
